As escolhas têm consequências: personagens podem agir e situações podem mudar enquanto o protagonista está ausente.
As saídas precisam ter lógica narrativa: não devem funcionar como teletransportes arbitrários.
Os sonhos originais são a referência principal: elementos inventados devem ser identificados como expansões narrativas.
Os mistérios não devem ser revelados antecipadamente: o jogador precisa descobri-los durante a exploração.
As conexões podem evoluir: novas descobertas podem revelar relações antes desconhecidas entre os territórios.
